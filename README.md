# 翻訳BOT ドキュメント

最終更新: 2026年10月10日 ／ `bot_google.py`（version 9-google）

## 概要

国旗の絵文字でリアクションすると、その言語に翻訳して、全員に見える返信として投稿する Discord BOT です。翻訳は **Google 翻訳（Cloud Translation – Basic v2）をメイン**、**DeepL をサブ** にしています。Google 翻訳が応答しないときは、自動で DeepL に切り替えます。

- 実行環境: Python 3.10 以上
- ライブラリ: `discord.py`、`aiohttp`、`python-dotenv`

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `bot_google.py` | BOT 本体（公開用） |
| `.env` | トークンと API キー（`.env.google.example` をコピーして作成） |
| `banned_users.json` | 翻訳を禁止したユーザー（自動生成） |
| `except_channels.json` | 例外チャンネル（自動生成） |

## セットアップ

1. `pip install -r requirements.txt` でライブラリを入れます。
2. `.env.google.example` を `.env` にコピーし、3つの値を設定します。

   ```
   DISCORD_TOKEN=Discord BOT のトークン
   GOOGLE_API_KEY=Cloud Translation API のキー
   DEEPL_API_KEY=DeepL API のキー
   ```
3. Google Cloud で「Cloud Translation API」を有効にし、API キーを作ります。キーは、このAPIだけに使えるよう制限してください。
4. Discord Developer Portal の Bot 設定で **Message Content Intent** をオンにします。
5. BOT を招待するときに、「チャンネルを見る」「メッセージ履歴を読む」「メッセージを送信」の権限を付けます。
6. `python bot_google.py` で起動します。ログに `bot version: 9-google` が出れば成功です。

DeepL の無料プランのキーは、末尾が `:fx` です。自動で無料用のURLを使います。

## 使い方

翻訳したいメッセージに国旗でリアクションすると、数秒後に翻訳が返信されます。返信の先頭に、国旗、言語名、使ったエンジン（Google または DeepL）が表示されます。

```
🇺🇸 English に翻訳しました（Google）:
```

約45種類の国旗に対応しています（日本語 🇯🇵、English 🇺🇸 🇬🇧、中国語 🇨🇳 🇹🇼 🇭🇰、韓国語 🇰🇷、フランス語 🇫🇷、ドイツ語 🇩🇪、スペイン語 🇪🇸 など）。全一覧は `bot_google.py` の `FLAG_LANGUAGES` にあります。

## コマンド

| コマンド | 実行できる人 | 内容 |
| --- | --- | --- |
| `!help` | 誰でも | コマンドの一覧を表示します。 |
| `!t-t 🇺🇸 文章` | 誰でも | 国旗の絵文字で言語を指定して、Google 翻訳と DeepL の両方で翻訳し、結果を並べて表示します。 |
| `!ping` | 管理者 | Gateway と API の遅延をミリ秒で表示します。 |
| `!t-ban @ユーザー` | 管理者 | そのユーザーの翻訳機能を禁止します。 |
| `!t-unban @ユーザー` | 管理者 | 禁止を解除します。 |
| `!t-except add [#チャンネル]` | 管理者 | 例外チャンネルに追加します。省略すると今のチャンネルです。 |
| `!t-except remove [#チャンネル]` | 管理者 | 例外チャンネルから外します。 |
| `!t-except list` | 管理者 | 例外チャンネルの一覧を表示します。 |

すべてのコマンドの結果は、チャンネルに返信として表示され、全員に見えます。管理者権限を持たない人が管理者用のコマンドを送っても、BOT は反応しません。

## 翻訳の仕組み

1. まず Google 翻訳で翻訳します。
2. 15秒以内に応答しない場合や、エラーの場合は、DeepL に切り替えます。
3. すでにその言語の文章に国旗を付けた場合は、切り替えずに「すでに 〜 の文章です」と通知します。
4. 両方失敗した場合は、「翻訳に失敗しました」と通知します。

メンション、カスタム絵文字、URL は、翻訳せずにそのまま残します。4,000文字を超えるメッセージは翻訳しません。同じメッセージと言語の組み合わせは、直近500件までキャッシュして、重複して翻訳しません。

## 禁止ユーザーと例外チャンネル

**禁止ユーザー**: `!t-ban` で追加したユーザーは、リアクションや `!t-t` を使っても無反応になります。禁止の対象は、リアクションを付けた人です。管理者権限を持つ人と BOT 自身は、禁止できません。

**例外チャンネル**: 例外チャンネルでは、管理者権限を持つ人だけが翻訳できます。それ以外の人がリアクションしても無反応です。スレッドは、親チャンネルの設定に従います。

どちらもサーバーごとに管理され、JSON ファイルに保存されるので、再起動しても残ります。

## 料金の目安

- **Google 翻訳（Basic v2）**: 月の最初の50万文字は無料で、超えた分は有料です。料金は、API キーを作ったプロジェクトに請求されます。
- **DeepL**: 無料プランは生涯で100万文字までです。
