# 翻訳BOT ドキュメント

**最終更新:** 2026年10月10日  
**bot_google.py version:** 10-google  

## 概要

国旗の絵文字でリアクションすると、その言語に翻訳して、全員に見える返信として投稿する Discord BOT です。翻訳は **Google 翻訳（Cloud Translation – Basic v2）** をメイン、**DeepL** をサブにしています。Google 翻訳が応答しないときは、自動で DeepL に切り替わります。-

**実行環境:** Python 3.10 以上  
**ライブラリ:** discord.py、aiohttp、python-dotenv

---

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `bot_google.py` | BOT 本体（公開用） |
| `.env` | トークンと API キー（`.env.google.example` をコピーして作成） |
| `banned_users.json` | 翻訳を禁止したユーザー（自動生成） |
| `except_channels.json` | 例外チャンネル（自動生成） |
| `whitelist.json` | ホワイトリスト・許可リスト（自動生成） |

## セットアップ

### 1. ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数ファイルの設定

`.env.google.example` を `.env` にコピーし、以下の3つの値を設定します。

```env
DISCORD_TOKEN=Discord BOT のトークン
GOOGLE_API_KEY=Cloud Translation API のキー
DEEPL_API_KEY=DeepL API のキー
```

- **Google Cloud:** 「Cloud Translation API」を有効にし、API キーを作成します。キーは、このAPI だけに使えるよう制限してください。
- **DeepL:** 無料プランのキーは末尾が `:fx` です。自動で無料用の URL を使います。

### 3. Discord Developer Portal の設定

1. **Message Content Intent** を ON にします。
2. **Server Members Intent** を ON にします（ホワイトリストの `add all` で必要）。
3. BOT を招待するときに、以下の権限を付けます。
   - チャンネルを見る
   - メッセージ履歴を読む
   - メッセージを送信

### 4. BOT を起動

```bash
python bot_google.py
```

## 使い方

### リアクション翻訳

翻訳したいメッセージに国旗でリアクションすると、数秒後に翻訳が返信されます。返信の先頭に、国旗、言語名、使ったエンジン（Google または DeepL）が表示されます。

```
🇺🇸 English に翻訳しました（Google）:
翻訳結果がここに表示されます
```

**対応している言語:** 約45種類の国旗に対応しています。
- 日本語 🇯🇵
- English 🇺🇸 🇬🇧 🇨🇦 🇦🇺
- 中国語 🇨🇳 🇹🇼 🇭🇰
- 韓国語 🇰🇷
- フランス語 🇫🇷
- ドイツ語 🇩🇪
- スペイン語 🇪🇸 🇲🇽
- 他多数

## コマンド

### 誰でも使えるコマンド

| コマンド | 内容 |
|---------|------|
| `!help` | コマンドの一覧を表示します。 |
| `!t-t 🇺🇸 文章` | 国旗の絵文字で言語を指定して、Google 翻訳と DeepL の両方で翻訳し、結果を並べて表示します。 |

### 管理者用コマンド

| コマンド | 内容 |
|---------|------|
| `!ping` | Gateway と API の遅延をミリ秒で表示します。 |
| `!t-ban @ユーザー` | そのユーザーの翻訳機能を禁止します。 |
| `!t-unban @ユーザー` | 禁止を解除します。 |
| `!t-except add [#チャンネル]` | 例外チャンネルに追加します。省略すると現在のチャンネルです。 |
| `!t-except remove [#チャンネル]` | 例外チャンネルから外します。 |
| `!t-except list` | 例外チャンネルの一覧を表示します。 |
| `!t-whitelist on` / `off` | ホワイトリストモードを切り替えます。`of` と入力しても `off` として機能します。 |
| `!t-whitelist add all` | 現在サーバーにいる全員を許可リストに追加します（後から参加した人は含まれません）。 |
| `!t-whitelist add @ユーザー` | そのユーザーを許可リストに追加します。メンション または ユーザーID で指定できます。 |
| `!t-whitelist remove @ユーザー` | 許可リストから外します。 |
| `!t-whitelist list` | ホワイトリストモードの状態と許可リストの人数を表示します。 |

すべてのコマンドの結果は、チャンネルに返信として表示され、全員に見えます。管理者権限を持たない人が管理者用のコマンドを送ると、BOT は反応しません。

## 機能詳細

### 翻訳の仕組み

1. Google 翻訳で翻訳します。
2. 15秒以内に応答しない場合やエラーが出た場合は、DeepL に切り替わります。
3. すでにその言語の文章に国旗を付けた場合は、「すでに 〜 の文章です」と通知します。
4. 両方失敗した場合は、「翻訳に失敗しました」と通知します。

**保護される要素：** メンション、カスタム絵文字、URL は、翻訳されずそのまま残ります。

**制限：**
- 4,000文字を超えるメッセージは翻訳しません。
- 同じメッセージと言語の組み合わせは、直近500件までキャッシュして、重複して翻訳しません。

### 禁止ユーザー

`!t-ban` で追加したユーザーは、リアクションや `!t-t` を使っても無反応になります。

**禁止対象:** リアクションを付けた人が禁止対象です。  
**禁止できない:** 管理者権限を持つ人と BOT 自身は禁止できません。

禁止リストはサーバーごとに管理され、JSON ファイルに保存されるため、再起動後も残ります。

### 例外チャンネル

例外チャンネルでは、**管理者権限を持つ人だけが翻訳できます。** それ以外の人がリアクションしても無反応です。

**スレッド:** スレッドは、親チャンネルの設定に従います。

例外チャンネルはサーバーごとに管理され、JSON ファイルに保存されるため、再起動後も残ります。

### ホワイトリストモード

ホワイトリストモード（`!t-whitelist on`）が ON のときは、**許可リストに入っている人と管理者だけが翻訳できます。** それ以外の人がリアクションしても無反応です。

**使い方の流れ:**
1. `!t-whitelist on` でモードを有効にします。
2. `!t-whitelist add all` で現在サーバーにいるメンバーを許可リストに追加します（BOT は除外）。
3. 後から参加した人は、`!t-whitelist add @ユーザー` で手動で追加します。

ホワイトリスト設定はサーバーごとに管理され、JSON ファイルに保存されるため、再起動後も残ります。

## 料金の目安

### Google 翻訳（Cloud Translation API - Basic v2）

- 月の最初の **50万文字** は無料
- 超えた分は有料（約 $15/100万文字）
- 料金は API キーを作ったプロジェクトに請求されます

### DeepL

- 無料プランは生涯で **100万文字** まで
- 超えた場合は有料プランへの移行が必要
